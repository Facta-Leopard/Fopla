## 소개

Fopla는 포지플레이 프로젝트를 위해 개발 중인 그래픽 API 번역 레이어입니다. 별도 저장소에서 개발 및 관리하며, 자체 독점 이용 조건에 따라 제공합니다.

이 저장소는 Fopla를 오픈소스 라이선스로 제공하거나 일반적인 사용 권한을 부여하지 않습니다.
